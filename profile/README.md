# Coverset examples

Read-only mirrors of popular open-source projects, kept so that [Coverset](https://github.com/coverset)
runs on real code and real review traffic, and example applications in Python, TypeScript and Rust.

A mirror's default branch is upstream's tip plus one commit that adds `.github/workflows/coverset.yml`.
Pull requests in a mirror are copies of open upstream pull requests. They are never merged, reviewed
or commented on by people. Review and discussion stay upstream; please do not open pull requests here.

`control` holds the sync and its policy. To have a project removed from this organization, open an
issue there.
